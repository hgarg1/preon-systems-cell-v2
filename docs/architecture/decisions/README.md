# Architecture Decision Records

Accepted architectural decisions for the Preon Systems Cell v2 digital organism runtime.

Each record documents a decision made about the system's design — the question that was asked, what was decided, the biological basis for the decision, how it maps to the digital implementation, and what was explicitly rejected.
